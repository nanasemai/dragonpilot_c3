## 修复方案

### 方案一：临时跳过数值验证（快速测试）

在 `.env` 文件中添加：

```bash
export SKIP_VALIDATION=1
```

这将绕过编译过程中的数值验证，允许项目启动。

### 方案二：优化 GPU 编译配置

修改 `.env` 文件中的 OpenCL 设置：

```bash
export CL_HALF=0              # 保持禁用 float16
export CL_INT64=1             # 启用 64位整数（提高精度）
export CL_OPTIMIZATION_LEVEL=1 # 改为保守优化
export SKIP_VALIDATION=1      # 临时跳过验证
```

### 方案三：使用 CPU 回退（最稳定方案）

修改 `.env` 文件：

```bash
export DEV=CPU                # 使用 CPU 替代 GPU
export SKIP_VALIDATION=1      # 跳过验证
```

### 下一步操作

1. 尝试方案一，测试是否能正常启动
2. 如果方案一成功，逐步尝试方案二或三以获得更好的性能
