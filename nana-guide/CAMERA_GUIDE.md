### 3.5 推荐方案详解

#### 3.5.1 方案A：单摄"万金油"方案 (推荐新手/低算力)

**核心逻辑**：不求最远，也不求最广，求一个"够用且稳定"的中间值。

**目标视角 (HFOV)**：60°

**采购镜头**：6mm (M12接口)

**适用场景**：绝大多数高速公路、城市快速路。

**代码策略**：使用C3的模型架构，但在输入时只喂这一路数据（或进行软件裁切）。

#### 3.5.2 方案B：双摄"真·C3X"方案 (推荐极客/高算力)

**核心逻辑**：术业有专攻，一个负责看百米之外，一个负责看车头加塞。

**主摄 (Narrow)**：
- **目标视角 (HFOV)**：45°
- **采购镜头**：8mm (M12接口)
- **作用**：这是你的"主眼睛"，负责车道保持和红绿灯。45° 比官方的 30° 更好安装，不容易因为震动丢失目标。

**副摄 (Wide)**：
- **目标视角 (HFOV)**：120°
- **采购镜头**：2.8mm (M12接口)
- **作用**：负责大急弯和近距离切入。

### 3.6 采购"防坑"提示

1. **焦距与底的匹配**：
   - 推荐的6mm/8mm/2.8mm镜头都是基于1/2.8英寸传感器 (Sony IMX291/307/335/415) 计算的
   - 如果使用1/4英寸传感器摄像头，同样的6mm镜头会导致视角更窄（变成望远镜）
   - 务必确认卖家标注的传感器尺寸是1/2.8"

2. **滤光片 (IR Filter)**：
   - 务必购买带650nm IR Filter (滤光片) 的镜头
   - 避免购买"无畸变"但"通透"的红外镜头，否则白天树叶会变成粉红色，红绿灯颜色会偏色

3. **接口类型**：
   - 认准M12接口 (S-Mount)，这是板载摄像头最通用的接口
   - 不要买成CS接口（太大）或M7接口（太小）

### 3.13 全局快门 vs 滚动快门

| 快门类型 | 推荐指数 | 特点 | 适用场景 |
|---------|---------|------|----------|
| 全局快门 | ★★★★★ | 整个画面同时曝光，无滚动失真 | 高速驾驶、快速移动物体拍摄 |
| 滚动快门 | ★★☆☆☆ | 逐行曝光，可能产生果冻效应 | 低速场景、静态物体拍摄 |

**全局快门的优势：**
- 消除高速运动时的图像失真（果冻效应）
- 提供更准确的物体位置信息
- 减少运动模糊
- 提高系统对快速变化场景的响应能力

**滚动快门的局限性：**
- 高速运动时产生图像扭曲
- 可能导致物体位置判断错误
- 影响车道线和障碍物检测精度

### 4.5 启动时自动配置

可以在启动脚本中添加摄像头参数配置，确保每次启动时都使用正确的设置：

```bash
# 在launch_chffrplus.sh中添加
if [ ! -f /AGNOS ]; then
  export USE_WEBCAM=1

  # 等待摄像头设备就绪
  sleep 2

  # 检查摄像头是否存在
  if [ -c /dev/video0 ]; then
    echo "正在设置摄像头参数..."

    # 相机参数调节（错误处理避免启动失败）
    v4l2-ctl -d /dev/video0 --set-ctrl=exposure_auto=1 2>/dev/null || echo "曝光设置失败，使用默认值"
    v4l2-ctl -d /dev/video0 --set-ctrl=white_balance_temperature_auto=1 2>/dev/null || echo "白平衡设置失败，使用默认值"
    v4l2-ctl -d /dev/video0 --set-ctrl=brightness=128 2>/dev/null || echo "亮度设置失败，使用默认值"
    v4l2-ctl -d /dev/video0 --set-ctrl=contrast=128 2>/dev/null || echo "对比度设置失败，使用默认值"
    v4l2-ctl -d /dev/video0 --set-ctrl=saturation=64 2>/dev/null || echo "饱和度设置失败，使用默认值"
    v4l2-ctl -d /dev/video0 --set-ctrl=sharpness=25 2>/dev/null || echo "锐度设置失败，使用默认值"
    v4l2-ctl -d /dev/video0 --set-ctrl=backlight_compensation=1 2>/dev/null || echo "逆光补偿设置失败，使用默认值"

    echo "摄像头参数设置完成！"
  else
    echo "警告：未找到摄像头设备 /dev/video0"
  fi
fi
```

## 4. 性能优化

### 4.1 摄像头延迟优化

#### 缓冲区优化

默认情况下，OpenCV VideoCapture 会使用较大的缓冲区（通常3-5帧），这会增加延迟。通过减少缓冲区大小可以显著降低延迟：

```python
import cv2

cap = cv2.VideoCapture(0)
# 实测结果 (2026-01-17):
# - BUF=3: 1080P MJPG 达到 19.8 FPS ✅
# - BUF=2: 1080P MJPG 只有 ~17 FPS
# - BUF=1: 只有 ~10 FPS
cap.set(cv2.CAP_PROP_BUFFERSIZE, 3)
```

**效果**: BUF=3 是最佳选择，可达到 ~20 FPS

#### 分辨率和帧率平衡

使用 **MJPG 压缩格式** 可以显著提高高分辨率下的帧率：

| 1920×1080 | YUYV | ~5 FPS | ⚠️ 仅静态场景 |
| 1280×720 | MJPG | **~20 FPS** | ✅ 平衡选择 |
| 1280×720 | YUYV | ~7 FPS | ⚠️ 帧率偏低 |
| 640×480 | MJPG | **~20 FPS** | ✅ 低带宽场景 |

**关键发现**: 使用 MJPG 压缩格式，USB 2.0 带宽下可实现 1080P @ 20 FPS！

焦距是摄像头光学系统的重要参数，它决定了摄像头的视野范围和成像大小。焦距越短，视野越宽，但远处物体的细节越少；焦距越长，视野越窄，但远处物体的细节越清晰。

|---------|---------|----------|------------|

| 中等焦距 | 70°-90° | 混合场景 | 车辆前挡风玻璃上方 |
| 长焦距 (长焦) | 45°-60° | 高速公路驾驶、远距离识别 | 车辆前挡风玻璃中央上方 |

### 5.4 焦距选择推荐

#### 5.4.1 道路摄像头

| 驾驶场景 | 推荐焦距 | 视野角度 | 优势 |
|---------|---------|---------|------|
| 城市道路 | 短焦距 (广角) | 120° | 覆盖更广的视野，适合复杂交通场景 |
| 高速公路 | 长焦距 (长焦) | 45°-60° | 提供更远距离的清晰识别 |
| 混合场景 | 中等焦距 | 70°-90° | 平衡视野范围和识别能力 |

#### 5.4.2 广角摄像头

对于广角摄像头，推荐使用更短的焦距：

| 应用场景 | 推荐焦距 | 视野角度 | 说明 |
|---------|---------|---------|------|
| 交叉路口辅助 | 超短焦距 | 120° | 覆盖更大的视野范围 |
| 停车场辅助 | 短焦距 | 120° | 提供车辆周围的全景视图 |

### 5.5 焦距与安装位置的关系

| 安装位置 | 推荐焦距 | 调整建议 | 注意事项 |
|---------|---------|----------|----------|
| 前挡风玻璃中央 | 中等焦距 | 略微向下倾斜 | 避免阳光直射和反光 |
| 前挡风玻璃上方 | 中等-长焦距 | 水平或略微向下倾斜 | 提供更远的视野 |
| 后视镜后方 | 短焦距 | 水平视角 | 隐藏安装，减少遮挡 |
| 车辆侧面 | 短焦距 | 向外倾斜 | 覆盖盲区 |

### 5.6 焦距计算方法

焦距（以像素为单位）可以通过以下公式计算：

```
焦距 (像素) = (传感器宽度 / 2) / tan(视野角度 / 2)
```

其中，传感器宽度可以通过分辨率和像素大小计算得出。

### 5.7 实际应用建议

1. **优先考虑视野范围**：对于自动驾驶辅助系统，足够的视野范围比远距离细节更重要
2. **测试不同焦距**：在实际安装前，测试不同焦距的摄像头效果
3. **考虑摄像头高度**：安装位置越高，可能需要更短的焦距来覆盖前方道路
4. **调整摄像头角度**：即使焦距固定，也可以通过调整摄像头角度来优化视野

## 9. 故障排除

### 9.1 常见问题及解决方案

| 问题 | 可能原因 | 解决方案 |
|------|---------|----------|
| 摄像头未被识别 | 驱动问题 | 安装或更新摄像头驱动 |
| 摄像头未被识别 | 线缆松动 | 检查USB线缆连接 |
| 摄像头未被识别 | 权限问题 | 确保用户在video组中：`sudo usermod -aG video $USER` |
| 图像太暗 | 曝光不足 | 调整曝光设置：`v4l2-ctl -d /dev/video0 --set-ctrl=exposure_auto=1` |
| 图像太亮 | 曝光过度 | 调整曝光设置：`v4l2-ctl -d /dev/video0 --set-ctrl=exposure_auto=1` |
| 颜色失真 | 白平衡问题 | 调整白平衡：`v4l2-ctl -d /dev/video0 --set-ctrl=white_balance_temperature_auto=1` |
| 图像模糊 | 焦距问题 | 调整摄像头焦距（如果支持） |
| 图像模糊 | 镜头脏污 | 清洁摄像头镜头 |
| 帧率低 | 分辨率过高 | 降低分辨率或帧率 |
| 帧率低 | USB带宽不足 | 使用USB 3.0接口 |
| 画面卡顿 | 系统负载高 | 关闭其他占用系统资源的程序 |
| 画面闪烁 | 电源不稳定 | 检查电源连接，使用稳压电源 |
| 无法设置分辨率 | 摄像头不支持 | 尝试较低的分辨率 |
| 无法设置分辨率 | 驱动限制 | 更新摄像头驱动 |

## 10. 常见问题解答

### 10.1 基础问题

**Q: 什么类型的摄像头最适合dragonpilot？**
A: 推荐按照以下优先级选择摄像头：
1. **视角合适**（70°-90°）：平衡视野范围和细节
2. **全局快门**：避免高速运动时的图像失真（果冻效应）
3. **分辨率1080P**（1920x1080）：无需代码调整，更高质量
4. **USB2.0接口**：价格便宜，完全支持1080P分辨率
5. **宽动态范围**：低光环境效果好

具体推荐：ELP USB2.0 1080P全局快门摄像头（宽动态, 视角70°-90°）或Hikvision USB2.0 1080P摄像头（宽动态）。

**Q: 摄像头的最低分辨率要求是什么？**
A: 最低建议使用640x480分辨率，但**强烈推荐使用1920x1080 (1080P)分辨率**，这样代码上不需要调整，且能获得更好的识别效果。

**Q: 我需要多个摄像头吗？**
A: 基本设置只需要一个主道路摄像头（ROAD_CAM）。广角摄像头（WIDE_CAM）和驾驶员监控摄像头（DRIVER_CAM）是可选的，根据您的需求添加。

### 10.2 技术问题

**Q: 如何确定摄像头的焦距？**
A: 可以通过代码中的CameraConfig查看默认焦距设置，或使用v4l2-ctl工具查看摄像头属性。对于自动驾驶，建议：
- 长焦摄像头：视野约45-60度，适合高速公路驾驶和远距离识别
- 广角摄像头：视野约120度，适合城市驾驶和复杂交通场景
- 中等焦距摄像头：视野约70-90度，适合混合场景

**Q: 为什么我的摄像头帧率很低？**
A: 可能的原因包括：分辨率过高、USB带宽不足、系统负载高或摄像头硬件限制。尝试降低分辨率或使用USB 3.0接口。

**Q: 如何调整摄像头的曝光设置？**
A: 使用v4l2-ctl工具：`v4l2-ctl -d /dev/video0 --set-ctrl=exposure_auto=1` 启用自动曝光，或手动设置曝光值。

**Q: 我的摄像头图像颜色失真怎么办？**
A: 调整白平衡设置：`v4l2-ctl -d /dev/video0 --set-ctrl=white_balance_temperature_auto=1` 启用自动白平衡。

### 10.3 安装问题

**Q: 最佳的摄像头安装位置在哪里？**
A: 推荐安装在前挡风玻璃中央上方，略微向下倾斜，以获得最佳的前方视野。

**Q: 如何固定摄像头而不损坏车辆内饰？**
A: 使用3M双面胶或吸盘支架进行无损安装，避免使用螺丝固定。

**Q: 摄像头线缆如何隐藏？**
A: 沿挡风玻璃边缘走线，使用线缆夹固定，避免影响安全气囊和其他车辆系统。

### 10.4 代码问题

**Q: 如何修改代码中的默认分辨率？**
A: 在`tools/webcam/camera.py`文件中修改Camera类和CameraMJPG类的初始化方法中的分辨率设置。

**Q: 如何添加新的摄像头配置？**
A: 在`common/transformations/camera.py`文件中修改DEVICE_CAMERAS字典，添加新的设备和传感器配置。

**Q: 如何调试摄像头问题？**
A: 使用v4l2-ctl工具检查摄像头属性，查看系统日志，或使用测试脚本验证摄像头功能。

### 10.5 性能问题

**Q: 高分辨率会影响系统性能吗？**
A: 是的，更高的分辨率会增加系统负载和内存使用。建议根据硬件性能选择合适的分辨率，默认的1280x720是一个很好的平衡点。

**Q: 如何优化摄像头性能？**
A: 使用MJPG格式、适当的分辨率和帧率、USB 3.0接口，并确保系统有足够的资源。

**Q: 摄像头延迟会影响自动驾驶吗？**
A: 是的，高延迟会影响系统的实时性。使用高帧率、低延迟的摄像头，并确保系统性能足够。
